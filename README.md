# Prueba de motores — ISELEC

PWA que guía al técnico en la prueba de motores de inducción trifásicos
multiconexión (6 y 12 hilos, menores de 600 V): registra mediciones, fotos y
observaciones, evalúa los criterios de aceptación y genera el informe PDF.

- **Frontend**: estático, sin build, publicado con GitHub Pages en
  `motores.iselec.com.pa`.
- **API**: PHP 8 + MySQL en cPanel (`api-motores.iselec.com.pa`), carpeta `api/`.

`prototipo-prueba-motores.html` es la referencia funcional del protocolo.

Estado: repositorio inicial, sin código de producción todavía.
